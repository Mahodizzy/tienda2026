Falta un paso en Firebase

Publica las reglas nuevas para que tu panel pueda guardar cambios.

  1. Abre Firebase → Firestore Database → pestaña Reglas.
  2. Borra todo y pega el contenido de firebase/firestore.rules (el de esta versión).
  3. Pulsa Publicar, espera un minuto y toca el botón de abajo.

Activa tu cuenta de administrador

Por seguridad, la primera vez debes darte permiso tú mismo desde Firebase. Solo se hace una vez.

Tu código
  1. Abre Firebase → Firestore Database → pestaña Datos.
  2. Toca Iniciar colección (o Agregar colección) y escribe admins.
  3. En ID del documento, pega tu código.
  4. Agrega un campo: nombre nombre, valor tu nombre. Pulsa Guardar.
